# مدرسه فرهنگ — School Management Platform

وب‌سایت و سامانهٔ مدرسهٔ ابتدایی پسرانهٔ «فرهنگ»: React + TypeScript + Tailwind، Node.js + Express، Prisma، MySQL.

## ساختار

```
farhang-school/
├── backend/      # API (Express + Prisma)
├── frontend/     # React (مرحلهٔ بعد)
├── database/     # SQL کمکی
├── docs/         # مستندات
├── SETUP-DATABASE.md   # راهنمای قدم‌به‌قدم Database  <-- از اینجا شروع کنید
└── README.md
```
